# Mineral Segmentation Application

Десктопное приложение для сегментации и разметки минеральных зерен на изображениях поляризованной микроскопии.

## Функционал

### Загрузка и обработка изображений
- Загрузка 4 изображений: PPL 45°, PPL 90°, XPL 45°, XPL 90°
- Автоматическое выравнивание изображений относительно друг друга
- Разбиение на патчи 1024×1024 пикселей
- Фоновая сегментация с отображением прогресса

### Просмотр и навигация
- Переключение между XPL 45° и XPL 90° (клавиша **X**)
- Переключение между XPL и PPL режимами (клавиша **P**)
- Отображение сегментов (клавиша **S**)
- Отображение границ (клавиша **B**)
- Масштабирование колесиком мыши
- Панорамирование правой кнопкой мыши
- Навигация по патчам стрелками

### Разметка
- Клик на сегмент для назначения тега минерала
- Выбор из существующих тегов или создание нового
- Автоматическая генерация уникальных цветов для тегов
- Карта обзора (minimap) с текущей позицией

### Сохранение
- Экспорт разметки в PNG файлы
- JSON файл с соответствием цветов и тегов
- Сохранение по патчам с координатами

## Системные требования

- **ОС**: Windows 10/11
- **Python**: 3.9 или выше
- **Node.js**: 18 или выше
- **RAM**: минимум 8 ГБ (рекомендуется 16 ГБ)
- **Место на диске**: ~2 ГБ

## Установка и запуск

### Вариант 1: Автоматический запуск (рекомендуется)

1. Клонируйте или распакуйте проект
2. Запустите `start.bat`
3. Дождитесь установки зависимостей и запуска приложения

### Вариант 2: Ручная установка

```bash
# 1. Установите Python зависимости
cd backend
pip install -r requirements.txt

# 2. Установите Node.js зависимости
cd ../frontend
npm install

# 3. Запустите backend (в отдельном терминале)
cd backend
python -m uvicorn main:app --reload --port 8000

# 4. Запустите Electron (в другом терминале)
cd frontend
npm start
```

### Вариант 3: Сборка EXE

```bash
cd frontend
npm run build-win
```

Исполняемый файл будет в папке `dist/`.

## Горячие клавиши

| Клавиша | Действие |
|---------|----------|
| X | Переключить XPL 45° / XPL 90° |
| P | Переключить XPL / PPL режим |
| S | Показать/скрыть сегменты |
| B | Показать/скрыть границы |
| ← → | Перейти к предыдущему/следующему патчу |
| ↑ ↓ | Перейти к патчу выше/ниже |
| Ctrl+O | Загрузить изображения |
| Ctrl+S | Сохранить проект |

## Алгоритм сегментации

1. **Денойзинг**: Mean shift фильтрация + инпейнтинг мелких деталей
2. **Первоначальная сегментация**: QuickShift или SLIC
3. **Построение RAG**: Region Adjacency Graph с весами на основе CIEDE2000
4. **Иерархическое слияние**: Объединение похожих регионов по порогу Delta E
5. **Комбинирование**: Объединение результатов XPL 45° и XPL 90°
6. **Постобработка**: Морфологические операции для чистых границ

## Устранение неполадок

### "Python is not installed"
Установите Python 3.9+ с https://www.python.org/
При установке отметьте "Add Python to PATH"

### "Node.js is not installed"  
Установите Node.js 18+ с https://nodejs.org/

### Ошибка "Module not found"
Переустановите зависимости:
```bash
cd backend && pip install -r requirements.txt --force-reinstall
cd ../frontend && npm install --force
```

### Медленная сегментация
- Убедитесь, что используете 64-битный Python
- Закройте другие ресурсоемкие приложения
- Увеличьте размер патча в настройках (по умолчанию 1024)
